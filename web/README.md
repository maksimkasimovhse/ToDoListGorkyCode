# Голосовой ассистент — фронтенд

Чистые JS (ES-модули) и CSS, без сборки и зависимостей. Пока бэкенда нет, фронт работает с заглушкой `js/mock/`. Она отвечает в форматах из `contracts.md` (v0.2) и проходит сценарии приёмки из ФТ, раздел 16.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. Голосовой ввод работает в Chrome, Edge и Safari. Нужен `localhost` или https, с `file://` модули и микрофон не работают.

## Структура

| Файл | Что делает |
|---|---|
| `js/config.js` | `USE_MOCKS`, адрес API, тайм-аут запроса |
| `js/api.js` | клиент API по разделу 2 контрактов; в режиме заглушки вызывает `js/mock/server.js` с теми же путями |
| `js/app.js` | связывает части: отправка сообщений, озвучка, выбор записи, напоминания |
| `js/chat.js` | история диалога, отрисовка ответов всех типов: `done`, `clarify`, `choose`, `confirm`, `conflict`, `results`, `info`, `error` |
| `js/planner.js` | правая панель «Мои записи»: вкладки, группировка по дням, галочка и удаление |
| `js/recent.js` | левая панель «Последнее»: поиск и фильтр по типам |
| `js/voice.js` | распознавание (Web Speech API, ru-RU) и озвучка (speechSynthesis) |
| `js/items.js`, `js/time.js` | подписи записей и даты в поясе пользователя |
| `js/mock/` | заглушка бэкенда: разбор фраз правилами, логика диалога, «база» в localStorage |

## Заглушка

- Время заморожено на моменте из ФТ: **четверг, 29 октября 2026, 12:00, Москва**. Фронт берёт «сейчас» из `/api/me`, поэтому вкладка «Сегодня» показывает 29 октября.
- Заранее есть три записи для сценариев поиска 15–17: задача «подготовить слайды к защите», выполненная задача «подписать договор аренды» и прошедшая встреча с Иваном 20 октября.
- Фразы разбираются правилами, а не LLM. Работают формулировки из ФТ и близкие к ним, но не любые.
- Помощники в консоли браузера:
  - `__mock.reset()` возвращает начальные данные;
  - `__mock.fireReminder()` имитирует срабатывание напоминания.

## Переход на бэкенд

В `js/config.js` поставить `USE_MOCKS: false` и указать `API_BASE`, если API на другом адресе. Остальной код не меняется.

## Что фронт предполагает сверх контракта v0.2

Это предложения в контракт. Их надо согласовать с бэкендом.

1. **`GET /api/items?sort=-created_at&limit=20&types=…`** — последние созданные записи для левой панели. Сейчас в контракте такого нет.
2. **`now` в ответе `GET /api/me`** — текущее время сервера. Нужно, чтобы «сегодня» на фронте совпадало с сервером, если часы на демо заморожены. Без поля фронт берёт время браузера.
3. **`session_id` создаёт фронт** (`s_<uuid>`) и хранит в localStorage. «Новый диалог» вызывает `POST /api/session/reset` и создаёт новый id.
4. **Ответ `GET /api/history`** — `{ "history": [ … ] }`. Голый массив тоже принимается.
5. **Токен для `GET /api/stream`** — в `?token=`, потому что EventSource не умеет отправлять заголовок `Authorization`.
6. **Нажатие кнопки** отправляет и `choice`, и `text` с подписью кнопки, чтобы она попала в историю.
7. **`POST /api/undo`** отвечает в формате `/api/message`. Если в ответе есть `reply`, он показывается в чате.
8. **Пустую речь и ошибки микрофона** фронт обрабатывает сам и на сервер не отправляет. Код `empty_speech` остаётся на случай, если `text` всё же пустой.

## Решения по макету

- Цвета типов взяты по легенде макета: встречи зелёные, задачи фиолетовые, напоминания жёлтые. На макете карточки окрашены не по легенде.
- Пустой четвёртый фильтр с синей точкой убран: в модели только три типа и нет своих меток.
- Правая панель называется «Мои записи», как в ФТ: в ней не только задачи.
- Добавлены элементы, которых нет на макете: переключатель «Озвучивать ответы» (обязателен по ФТ 3), «Новый диалог», галочка «выполнено» и удаление в списке, просроченные задачи, задачи без времени и со сроком-периодом.
